# Data

The source file (about 228 MB) exceeds GitHub's file size limit, so it is not stored here. It is free and public.

1. Go to the FFIEC HMDA Data Browser: https://ffiec.cfpb.gov/data-browser/
2. Select **2025**, **Nationwide**
3. Filter: **Loan Type = VA guaranteed (3)**, **Loan Purpose = Home purchase (1)**
4. Download the CSV and save it here as `loan_types_3_loan_purposes_1_year_2025.csv`

Field definitions: https://ffiec.cfpb.gov/documentation/publications/loan-level-datasets/lar-data-fields
